# Fanart Trung Thu

Bỏ ảnh fanart vào thư mục này (jpg, png hoặc webp, nên dưới 1MB), rồi thêm một dòng vào `trung-thu-data.js`:

```js
{ tacGia: "Tên người vẽ", kenh: "@kenh", anh: "fanart/ten-file.jpg", link: "https://...", qua: 50000, daGui: false },
```

Khi đã gửi quà, đổi `daGui: false` thành `daGui: true`.
